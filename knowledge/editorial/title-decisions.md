# Title Decisions

사람 편집자가 검토한 제목 후보 전체와 선택 결과를 장기 편집 지식으로 누적합니다.
기존 기록은 수정하거나 덮어쓰지 않으며 새로운 결정만 아래에 추가합니다.
선택된 후보는 `selected`, 선택되지 않은 후보는 `rejected`로 기록합니다.
모든 최초 선택은 `hypothesis`이며 미발행 초안의 기록은 학습 데이터가 아닙니다.
실제 발행 성과를 사람이 검토한 뒤 별도 validation 이벤트가 추가된 결정만 `validated`로 인정합니다.
향후 자동 제목 순위화는 `validated` 결정만 사용할 수 있습니다.
기존 가설을 수정하지 말고 같은 `Decision ID`를 참조하는 새 이벤트를 추가합니다.
이 기록은 현재 제목 자동 선택에 사용하지 않습니다.
