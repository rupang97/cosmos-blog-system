# COSMOS 이미지 제작 가이드

## 적용 범위

이 가이드는 모든 썸네일과 인포그래픽의 생성, 검수, 저장 작업에 적용합니다.

## 필수 시퀀스

1. 발행 글의 제목, 검색 의도, 근거 있는 핵심 내용을 확인합니다.
2. 글의 `## 썸네일 프롬프트`, `## 인포그래픽 1 프롬프트`, 필요 시 `## 인포그래픽 2 프롬프트`를 원본으로 사용합니다.
3. 썸네일은 정보 전달형 문구 3개와 홈판 궁금증 유도형 문구 3개를 먼저 제시합니다. AI가 최종 문구를 추천하거나 자동 선택하지 않습니다.
4. 사람 편집자가 여섯 후보 중 최종 문구를 직접 선택합니다. 선택 전에는 최종 이미지 프롬프트를 작성하거나 이미지를 생성하지 않습니다.
5. 선택된 제목·보조 문구·단계 문구를 프롬프트에 따옴표로 정확히 기록합니다.
6. 프롬프트에 한글 문구의 `verbatim` 렌더링, 이미지 안 배치, 고대비 가독성, 텍스트 추가·누락·번역·변형 금지를 명시합니다.
7. 인포그래픽은 `Canvas size: WIDTHxHEIGHT` 형식으로 허용된 정사각형 또는 가로형 크기를 반드시 기록합니다.
8. 이미지를 생성합니다. 텍스트 없는 대체 이미지나 별도 텍스트 오버레이는 허용하지 않습니다.
9. 원본 문구와 이미지 속 문구를 글자 단위로 대조하고, 오탈자·누락·추가 텍스트·가독성을 검수합니다.
10. 검수를 통과한 이미지만 `images/<글파일명>/`에 버전 파일명으로 저장하고, 매니페스트 상태를 `approved`로 변경합니다.

## 텍스트 규칙

- 썸네일에는 확정된 제목 또는 핵심 문구를 이미지 안에 넣습니다.
- 인포그래픽에는 확정된 제목과 모든 단계·라벨을 이미지 안에 넣습니다.
- 문구는 글의 제목·본문·검증된 키워드와 일치해야 합니다.
- 과장, 보장, 공포 조장, 근거 없는 수치·브랜드·가격·로고를 추가하지 않습니다.
- 텍스트가 정확하지 않은 결과는 승인하지 않고 다시 생성합니다.

## 이미지 비율과 저장 규칙

- 썸네일: `1024x1024`
- 인포그래픽: `1024x1024`, `1024x768`, `1024x576` 중 하나
- 세로형 인포그래픽은 만들지 않습니다.
- 저장 위치: `images/<글파일명>/`
- 파일명: `thumbnail-vN.png`, `infographic-01-vN.png`, `infographic-02-vN.png`
- 매니페스트에는 원본 글, 프롬프트 원본, 캔버스 크기, 생성 방식, 검수 상태를 기록합니다.

## 승인 전 체크리스트

- [ ] 이미지 주제와 글의 검색 의도가 일치한다.
- [ ] 이미지 안의 한글 문구가 프롬프트 원문과 정확히 일치한다.
- [ ] 작은 화면에서도 제목과 단계 문구를 읽을 수 있다.
- [ ] 캔버스 크기가 정사각형 또는 가로형 규칙에 맞는다.
- [ ] 저장 위치와 버전 파일명이 규칙에 맞는다.
