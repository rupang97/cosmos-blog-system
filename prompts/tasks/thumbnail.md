# Thumbnail Task

Purpose: Define the prompt contract for thumbnail direction.

- Article title: `{{TITLE}}`
- Visual concept: `{{VISUAL_CONCEPT}}`
- Required outcome: A concise, on-brand thumbnail prompt.

## Attention Keywords

- Extract one primary topic keyword and one short benefit or problem keyword from
  the article title and core message.
- Include 1–2 short Korean text phrases that make the topic immediately clear.
  Keep each phrase to 2–6 Korean words.
- Place the primary phrase prominently and the secondary phrase only when it
  improves clarity. Do not use more than two text phrases.
- Use specific, truthful wording. Do not use fear-based, exaggerated, or
  unsupported clickbait.
- State the exact Korean phrases in quotation marks in the image prompt and
  request high-contrast, large, readable typography with sufficient empty space.
- If the image-generation tool cannot render Korean text reliably, generate the
  image without embedded text and return the exact overlay copy separately.
