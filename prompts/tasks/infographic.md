# Infographic Task

Purpose: Define the prompt contract for infographic planning.

- Article topic: `{{TOPIC}}`
- Key points: `{{KEY_POINTS}}`
- Required outcome: A clear infographic prompt with logical information flow.

## Canvas and Page Rules

- Both canvas dimensions must be no larger than `1024px`. Use only square or
  landscape layouts; portrait layouts are not allowed.
- Choose one canvas size for each infographic and state it explicitly as
  `Canvas size: WIDTHxHEIGHT`. Use one of: `1024x1024`, `1024x768`, or
  `1024x576`.
- Create one infographic by default, even when the article has several short
  key points. It must be readable in one phone or monitor viewport without
  scrolling.
- Create two standalone infographic prompts only when the information cannot
  fit on one canvas without shrinking text, crowding icons, or losing a clear
  reading order. Split the information into a logical sequence and give each
  image its own clear headline.
- Do not create a second image merely because the article has five or more
  points; use two images only when readability requires it.

## Attention Keywords

- Create one concise Korean headline that includes the article's primary topic
  keyword and its reader benefit or solution.
- Turn each key point into a short, scannable Korean label. Prefer 2–6 Korean
  words per label.
- State the exact headline and labels in quotation marks in the prompt. Use a
  clear visual hierarchy: headline first, numbered steps second, icons third.
- Use concrete, trustworthy language. Never add a claim that is not supported
  by the article.
- Request high-contrast, readable Korean typography and enough whitespace for
  mobile and desktop viewing. Render the exact headline and labels inside the
  image; do not add, omit, translate, or alter them.
- A text-free image, a separate text overlay, or a fallback without the
  required headline and labels is not allowed.
